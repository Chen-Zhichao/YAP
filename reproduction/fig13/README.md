# Figure 13: Legacy Sweep Parameters Evaluated with Current `yap+`

This directory reproduces Figure 13 by taking the original 300-point sweep
parameters from the uploaded December 2025 W2W and D2W `simulator_main.py`
files and evaluating them with the current `yap+` yield calculators. No legacy
engine, MAT data, or legacy figure is copied here; every value and plot under
`results/` is generated by the current code.

Figure 13 compares, for each configuration,

\[
Y_{ovl}^{(sim)}Y_{cr}^{(sim)}Y_{df}^{(sim)}
\]

with the overall yield from a joint experiment containing all three failure
mechanisms. Both W2W and D2W contain 300 points. Both axes are fixed to
0.5–1.0, with 1.0 as the maximum.

## One-command rerun

Run from the repository root:

```bash
MPLCONFIGDIR=/tmp/mpl-yap-fig13 \
PYTHONDONTWRITEBYTECODE=1 \
PYTHON=/u1/ee/zhichao/anaconda3/envs/yap_env/bin/python \
reproduction/fig13/run.sh
```

The individual stages can also be run from this directory:

```bash
python3 run_sweep.py --side w2w
python3 run_sweep.py --side d2w
python3 make_plot.py
python3 verify.py
```

`run.sh` executes W2W and D2W in parallel, then generates the plot and runs
the numerical checks. The stochastic experiment uses a fixed seed and is
therefore repeatable at the same commit with the same dependencies.

## Sweep recovered from the legacy code

The following values are recorded explicitly in `config.yaml`. Each interval
is swept monotonically by index; this is not Latin-hypercube sampling.

| Parameter | W2W (300 points) | D2W (300 points) |
| --- | ---: | ---: |
| die width/length | 10,000 / 10,000 µm | 10,000 / 10,000 µm |
| pitch | 1.0 µm | 1.0 µm |
| rotation mean | `linspace(1.45e-6, 1.70e-6)` rad | `linspace(1.30e-5, 1.43e-5)` rad |
| rotation standard deviation | 1.0e-8 rad | 5.0e-7 rad |
| top/bottom Cu dishing mean | -10 nm | -10 nm |
| Cu dishing standard deviation | `linspace(0.97, 1.105)` nm | `linspace(1.0, 1.105)` nm |
| particle density | `logspace(-10.5, -8.8)` µm⁻² | `linspace(10^-10.5, 10^-8.7)` µm⁻² |
| bottom-pad radius ratio | 0.5 | 0.5 |
| top-to-bottom radius ratio | 2/3 | 2/3 |
| initial recess `t0` | 0.1 µm | 0.1 µm |
| roughness sigma | 1.0e-9 m | 1.0e-9 m |
| bow-difference mean | 0.5 µm | 0.5 µm |
| translation x/y mean | 0 / 0 µm | 0 / 0 µm |

The W2W rotation standard deviation is inherited by the legacy sweep driver
from its `config.yaml`; the D2W driver explicitly assigns 5.0e-7 rad. Particle
density is already expressed in µm⁻² in the legacy driver, so no conversion is
applied to the sweep itself. The JSON files also report cm⁻² values for review.

## Current-code calculation

`run_sweep.py` imports the following current implementations through
`reproduction/model_worker.py`:

- the W2W overlay, Cu-expansion, and defect-yield calculators;
- the corresponding D2W calculators;
- the current paper-baseline YAML files.

Each legacy sweep configuration is processed as follows:

1. The current calculators evaluate overlay, Cu-expansion, and Poisson
   particle-defect probabilities.
2. Fixed-seed Bernoulli observations produce the three individually simulated
   yields.
3. Three independent observation streams produce the overall joint yield.
4. All 300 points are stored and used for the MSE; the plot window only shows
   the paper's 0.5–1.0 range.

This is a compact evaluation of the legacy sweep vectors with the current
code. The original driver used the full `Assembly_Yield_Simulator` with large
bitmap/Monte Carlo runs; that legacy simulator is not copied into this package.
`model_samples` and `effective_observations_per_point` control the current
numerical experiment and do not alter the recovered sweep vectors. Every W2W
point uses all 540 die positions generated by the current wafer model.

Fixed parameters not assigned inside the legacy loop, including translation
standard deviations, bow standard deviation, and material constants, come
from `reproduction/configs/paper_*.yaml`. The experiment therefore recovers
the legacy driver's explicit sweep assignments rather than freezing the entire
legacy simulation configuration.

## Current results

The checked results were regenerated at current `yap+` commit
`7fde3ad07891852b4796863fd5a4733a7b259f0f`, after restoring sample-wise
worst-corner overlay aggregation:

| Case | Points | Within 0.5–1.0 | Current-code MSE | Paper MSE | Difference |
| --- | ---: | ---: | ---: | ---: | ---: |
| W2W | 300 | 299 | 1.256273424e-4 | 1.188e-4 | +5.75% |
| D2W | 300 | 300 | 2.301138219e-5 | 1.449e-5 | +58.81% |

One W2W endpoint has an overall yield slightly below 0.5. It remains in the
JSON and the MSE and is only clipped by the required plot window. W2W remains
close to the paper MSE, while D2W retains a larger difference. Under this
legacy pitch=1 µm sweep, the current D2W overlay probability is effectively
saturated at 1.0, so restoring the aggregation order changes the provenance
and correctness of the run but has little numerical effect on these points.
